# Praktikum-Jarkom-A-Dhika-Aditya

Link Video TA 1 : https://youtu.be/miVqtvoVYG8

Kesimpulan Praktikum :
1. Apabila Interface router belum menggunakan no shutdown maka interface dapat tetap dalam kondisi tidak aktif sehingga jalur komunikasi melalui interface tersebut tidak dapat digunakan. Pada modul, no shutdown digunakan untuk mengaktifkan G0/0 dan G0/1.
2. Jika Salah memilih interface konfigurasi IP dapat diterapkan pada interface yang tidak terhubung dengan perangkat yang seharusnya, sehingga koneksi tidak berjalan sesuai topologi.
3. Jika Konfigurasi tidak disimpan maka konfigurasi yang sedang berjalan dapat tidak tersedia setelah perangkat melakukan restart. Karena itu perlunya penggunaan copy running-config startup-config pada switch dan router.
